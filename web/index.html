Privacy Policy for Wazir

Effective date: March 17, 2026

Wazir is a Chrome extension that helps users analyze finished chess.com games using local Stockfish analysis.

1. Information Wazir may access

On supported chess.com game pages, Wazir may access limited website content required for its core functionality, including:

  • Game ID
  • Game type or page context
  • Chess.com usernames visible on the game page
  • PGN-related metadata needed to identify the selected game
  • PGN text provided by the user or retrieved for analysis

2. How this information is used

Wazir uses this information only to:

  • Identify the currently open finished chess.com game
  • Retrieve the correct PGN for that game
  • Run game analysis inside the extension
  • Display move classifications, accuracy, ACPL, charts, and board review

3. Local analysis

Wazir runs Stockfish analysis locally inside the extension using packaged extension resources. Wazir does not download or execute remote JavaScript or remote WebAssembly as part of its analysis functionality.

4. Data sharing

Wazir does not sell personal data. Wazir does not use user data for advertising. Wazir does not use or transfer user data for creditworthiness, lending decisions, or unrelated profiling.

If PGN retrieval is performed through a Wazir-operated API, Wazir may send the minimum information required to locate the selected game PGN, such as username, game ID, and archive lookup context. This is used only for the extension’s core functionality.

5. Data storage

Wazir does not permanently store analyzed game data on external servers unless explicitly stated otherwise. Temporary processing may occur as needed to return PGN data for the selected game.

6. User choices

Users choose when to open the extension, fetch a PGN, and run an analysis. Wazir is intended for user-initiated review of finished chess games.

7. Third-party services

Wazir may communicate with:

  • chess.com pages selected by the user
  • public or Wazir-operated PGN retrieval endpoints

8. Children’s privacy

Wazir is not directed to children under 13 and does not knowingly collect personal information from children.

9. Changes to this policy

This privacy policy may be updated from time to time. Any changes will be reflected on this page.

10. Contact

11. Non-affiliation notice

Wazir is an independent project and is not affiliated with, endorsed by, or sponsored by Chess.com.
